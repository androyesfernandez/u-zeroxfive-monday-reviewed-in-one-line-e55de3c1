A tiny Node program that writes a one-line review of a Monday to `/output/entry.txt`. The line opens with a Monday-morning panic about being fired, then turns it into a shared dream — and HR is already printing the paperwork.

## Run

```sh
node main.ts
```

Requires Node 22. No dependencies, no network access.
